# Documentación técnica de proveedores externos

Convención heredada de segurolotengo-demo: la documentación que publica un
proveedor externo (BCP, BCB/OpenBCB, Meta) vive agrupada acá, nunca suelta en
la raíz de `docs/`. En la raíz quedan los documentos propios del proyecto.

Cuando se obtenga un contrato técnico oficial (por ejemplo, la especificación
de la API de pagos del BCP u OpenBCB), gobierna al adaptador correspondiente:
**no inventar parámetros ni endpoints distintos a los documentados**.
